This project is an AI-powered FRM (Financial Risk Manager) Level 2 study assistant built using:

📚 FRM study materials (converted into embeddings)
🔍 FAISS vector database for semantic search
🤖 Google Gemini for intelligent explanations
🖥️ Streamlit UI (optional / local run)
⚙️ Windows batch file for one-click execution

The system works completely offline for retrieval + online for AI reasoning, making it a hybrid learning assistant.
